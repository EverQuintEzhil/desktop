# Skills

## Description

Step-by-step guides that teach your agent how to handle one specific kind of task well.

## Detail

**What it is**

A how-to guide for one particular job — for example, how your team formats its reports, or the checklist to follow when reviewing a document.

**What your agent can do with it**

- Open the guide when the conversation calls for that kind of task
- Follow its steps and formats exactly, the same way every time
- Carry many specialties without cluttering its everyday instructions

**Example**

You add a _"Monthly report format"_ skill. When you ask for the monthly report, your agent follows that guide — right sections, right order, right tone — instead of improvising a new layout each time.

**Good to know**

A skill can be set to always apply, or to load only when it's relevant. Skills can also include reference files the agent consults while following the guide.
