# Data Stores

## Description

A source of information — documents, databases, file storage, or APIs — that your agent can search and work with.

## Detail

**What it is**

A source of information your agent can draw on. That can be documents you upload, or a connection to where your information already lives — a database (where a business keeps its records), a file store (like a shared company drive), or another app's data service (an API).

**What your agent can do with it**

- Search and read it: find the relevant passage or record and use it to answer you
- Use every action available for that source — adding a data store gives your agent the full set of tools that work with it
- Point back to where the information came from, so you can verify it

**Example**

Ask _"What's our refund policy?"_ — your agent finds the answer inside the policy document you added and quotes it back. With a data store connected to your orders database, ask _"How many orders shipped last week?"_ and your agent looks it up for you.

**Good to know**

Adding a data store gives your agent **all** the actions (tools) available for it. If you'd rather allow just one specific action — say, only looking up records, but not changing them — add that single tool instead (see Tools).
