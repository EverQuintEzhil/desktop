# Connectors

## Description

Connect your agent to apps you already use, so it can look things up and take action for you.

## Detail

**What it is**

A connection between your agent and another app you already use — your calendar, file storage, task tracker, and so on. (Technically this is called an "MCP server", but "connector" is all you need to remember.)

**What your agent can do with it**

- Look up information for you: calendar events, files, records
- Take action on your behalf: create a task, send an update, add an entry

**Example**

Ask _"Do I have any meetings tomorrow?"_ — with a calendar connector added, your agent checks your calendar and answers directly, instead of telling you to go look yourself.

**Good to know**

Some connectors ask you to sign in the first time, just like logging into an app on your phone. You can add or remove connectors at any time without rewriting your agent's instructions.
