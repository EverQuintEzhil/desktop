# Memories

## Description

Details your agent remembers from past conversations, so you don't have to repeat yourself.

## Detail

**What it is**

The things your agent picks up as you talk to it — your preferences, facts you've mentioned, useful context — kept from one conversation to the next.

**What your agent can do with it**

- Remember details you've shared instead of asking for them again
- Personalize its answers using what it already knows about you
- Bring up only what's relevant to the current conversation

**Example**

You once mention _"our reporting deadline is the last Friday of the month."_ Weeks later, when you ask about the report schedule, your agent already knows the deadline — you don't have to say it again.

**Good to know**

Without a memory added, every conversation starts from a blank slate. With one, your agent gradually gets to know you and what you're working on.
