# Model

## Description

The AI engine that powers how your agent thinks and replies.

## Detail

**What it is**

The underlying AI that reads your messages and writes your agent's replies — the engine under the hood.

**Why it matters**

- Models differ in how fast they respond
- They differ in how much they cost to run
- They differ in how deeply they can reason through a hard problem

**Example**

An agent that answers quick everyday questions does well with a fast, economical model. An agent that analyzes long contracts is worth pairing with a more capable one.

**Good to know**

You can add more than one model. The first in the list is used by default; the others are available as alternatives. Pick a default that matches what you'll mostly use this agent for.
