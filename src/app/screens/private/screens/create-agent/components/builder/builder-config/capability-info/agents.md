# Agents

## Description

Other agents this agent can hand work to when a task needs a specialist.

## Detail

**What it is**

Another agent that this agent can pass work to — like a colleague with a specialty. Instead of teaching one agent to do everything, you build a small team of focused agents that help each other.

**What your agent can do with it**

- Hand off the part of a request that the other agent is better at
- Wait for the specialist's answer and use it in its own response
- Combine results from more than one specialist into a single reply to you

**Example**

You ask _"Review this contract and draft a reply to the client."_ Your agent sends the contract to a contract-review agent, gets back the key points, and then writes the reply itself.

**Good to know**

Each added agent works from its own instructions and abilities. You see one conversation — the hand-offs happen behind the scenes.
